# POORPLIX — Portal Institucional

Portal institucional estático da POORPLIX, com identidade visual branca,
detalhes pretos e layout responsivo.

## Estrutura

```text
POORPLIX-PORTAL/
├── index.html
├── pages/
│   ├── sobre.html
│   ├── fundador.html
│   ├── contato.html
│   └── legal/
│       ├── privacidade.html
│       ├── termos.html
│       └── exclusao-de-dados.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── images/
└── README.md
```

## Hospedagem

O projeto é estático. Não exige Node.js, banco de dados ou servidor próprio.

Publique o conteúdo desta pasta em uma hospedagem estática. O arquivo
`index.html` deve permanecer na raiz publicada.

## URLs para cadastrar na Meta

Depois de publicar, substitua `SEU-ENDERECO` pelo endereço real do site:

- Política de Privacidade: `https://SEU-ENDERECO/pages/legal/privacidade.html`
- Termos de Serviço: `https://SEU-ENDERECO/pages/legal/termos.html`
- Exclusão de Dados: `https://SEU-ENDERECO/pages/legal/exclusao-de-dados.html`

## Revisão antes da publicação

Os documentos legais são modelos iniciais. Revise a Política de Privacidade
para refletir os dados efetivamente coletados, os serviços e fornecedores
utilizados, os prazos reais de retenção e as práticas de segurança existentes.
Revise também os Termos para que correspondam aos serviços e contratos reais.

Não publique informações que não correspondam à operação real da POORPLIX.
Os textos não afirmam a existência de CNPJ, registro empresarial ou certificações.
